# OA-CXR 公开复现版

本仓库提供主方法的两阶段训练、数据准备、固定划分、单图推理和评价代码。
[模型权重](https://huggingface.co/wanghekai/OA-CXR)包含图像模型、选中的神经读出与
fit-only 标准化参数；下载脚本固定版本并逐文件验证 SHA256。

请按[英文首页](README.md)的命令安装、下载、训练和评价，数据来源与文件版本见
[数据说明](docs/DATA.md)，实验参数与验收范围见[复现说明](docs/REPRODUCIBILITY.md)。

默认权重是论文主模型：seed 17，图像第 12 轮，线性 L1 神经读出第 27 轮。
训练入口执行完整 13 轮图像训练，再训练三个候选读出各 30 轮，仅用开发集选模。
部署时不读取原图、裁剪坐标、源身份或真值肺掩码。

原始医学图像需要从对应数据提供方获取。V7 衍生标注掩码附原作者归属与 CC BY 4.0
许可；MAIRA-2 权重不随仓库发布，应自行向官方获取。

任务是相对源图可见标注区域的解剖保留率，不是临床诊断或报告正确性判断。
已看过的来源仍标为探索性评价；bootstrap 区间不能替代多随机种子训练。
